E-LEAP OFFLINE BACKUP MASTER
Objectives B1 · Unit 3 · What's your job?

PURPOSE
This folder is the emergency classroom fallback when Vercel/Production is unavailable.

FASTEST USE — ONE COMPUTER / PROJECTOR
1. Download this folder or the branch ZIP.
2. Open index.html in Chrome.
3. Use Teacher mode.
4. Show answer, Check, Reset, Timer, Responses and Presentation work locally.
5. Student mode can be demonstrated on the same computer.

MULTI-DEVICE CLASSROOM ON THE SAME WI-FI
Requirements: Node.js installed on the teacher computer.
1. Open Terminal in this folder.
2. Run: node server-network.js
3. Open the Teacher URL printed in Terminal (normally http://localhost:8787).
4. Click Live Class / QR.
5. Students scan the QR or type the LAN URL shown.
6. Students submit answers; Teacher opens Responses to inspect the shared board.
7. Keep Terminal open during class.

IF THE QR IMAGE DOES NOT LOAD
The QR picture uses an external QR image service. The join URL is always displayed, so students can type it manually. The lesson and response server itself do not require Vercel.

MEDIA
This emergency package does not depend on cloud media to keep the lesson navigable. Source-dependent audio/photo activities display usable learning prompts and answer fields even when media is unavailable. Approved media can later be copied into this folder without changing the lesson flow.

DESIGN / INTERACTION STANDARD
- Fresh deep military green + lime accent + cream/white surfaces.
- Large classroom typography and no required vertical scrolling for normal activity screens.
- Teacher: Check · Reset · Show answer · Presentation · Timer · Responses · Live Class / QR.
- Student: Check · Reset · response entry. Teacher-only controls are hidden in Student mode.
- Show answer reveals answers in-place in the actual response boxes.
- Slide 5 uses Part 1 = 4 items and Part 2 = 3 items.
- Listening detail uses balanced Part 1 / Part 2 grouping.
- Present-tense screen reveals one sentence at a time.
- Higher-cognitive Clue Challenge replaces repetitive simple job ticking.

SOURCE BASIS
The lesson content follows the final Objectives B1 Unit 3 content package and the source teaching PPTs. Textbook activity numbering and known editorial corrections are preserved where supported by the sources.

# E-LEAP Media Externalization — GitHub SAFE

This package intentionally excludes lesson image, audio and video binaries.

Production rule:
- GitHub: platform code, schemas, lesson data, manifests, lightweight UI assets.
- Private media storage: licensed/cleared images, audio and video.
- Resource Registry / media audit: stable references, copyright status and access policy.

Golden Reference lesson code/data is retained. Media paths remain as references so the same lessons can be reconnected to approved private storage without redesigning the lesson.

Copyright status remains AMBER/private-until-cleared unless a resource has been explicitly cleared.

# Deploy to GitHub Pages

This package is static and can be deployed directly from the repository root.

## Recommended
Repository → Settings → Pages

Use:
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

Then save.

`index.html` is already in the repository root and `.nojekyll` is included.

## Update workflow
1. Test locally.
2. Commit changes.
3. Push to `main`.
4. GitHub Pages republishes automatically.

## Important
Do not upload copyrighted/private course media to a public repository.

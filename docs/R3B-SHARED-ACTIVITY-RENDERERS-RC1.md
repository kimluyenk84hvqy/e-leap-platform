# R3B Shared Activity Renderers RC1

Purpose: move E-LEAP away from lesson-specific controllers and toward one shared runtime.

Included in RC1:
- Matching renderer
- Ordering renderer
- Categorising renderer
- Listening/video response wrapper
- Speaking recorder foundation
- Poll renderer
- Writing/fill/discussion shared response renderer
- Student local autosave/restore foundation
- Shared media resolver for image/audio/video/document references
- Research events for autosave and recording lifecycle

Not final in RC1:
- Server-side persistence of drafts/recordings
- Live Responses transport
- Media Library UI and transcoding
- Full scoring for matching/ordering/categorising
- Assignment/Mock Test policy engine

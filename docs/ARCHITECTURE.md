# E-LEAP Platform Architecture — APPROVED

## Locked top-level areas
1. Courses
2. Skills Lab
3. Assignments
4. Mock Tests
5. Progress

## Locked content model
Course → Unit → Lesson → Activity

## Class model
Student ↔ Enrollment ↔ Class

Class Session → references reusable Lesson Content

## Assessment model
Assignment → Submission → Grade / Feedback

## Core rule
New courses, units, lessons and classes must be added as data/content. Do not redesign the platform shell for each course or unit.

## Copyright / privacy rule
Do not publish copyrighted course media, student submissions, private audio/video, or student data to public GitHub.

# E-LEAP Advanced Skills Learning Loop v1.0

Locked architecture: Advanced Skills/BG (LEARN) → Skills Lab (PRACTISE) → Mock Tests (ASSESS) → Progress (DIAGNOSE) → targeted return.

## Reuse rule
Core teaching modules exist once. CEFR is competency/level metadata. VSTEP and IELTS are assessment pathways; exam-specific strategy modules are added only when genuinely different.

## Writing
Writing Foundations; Paragraph Writing; Letter & Email Writing; Essay Writing; Visual Data Writing; Exam Strategies.

## Listening
Listening Foundations; Conversations & Dialogues; Monologues & Talks; Exam Strategies.

## Reading
Reading Foundations; Meaning & Vocabulary; Critical Reading; Text Organisation; Exam Strategies.

## Speaking
Speaking Foundations; Social Interaction; Describing & Narrating; Opinions & Discussion; Extended Speaking; Exam Strategies.

## Management
Authorized teacher/admin UI exposes Add, Rename, Move, Reorder, Hide/Show and Archive while preserving stable IDs. Current package provides a local Preview persistence adapter; Production persistence requires authenticated server-side storage.

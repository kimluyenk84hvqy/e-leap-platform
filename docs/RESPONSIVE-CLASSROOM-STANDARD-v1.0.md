# E-LEAP Responsive Classroom Standard v1.0

Status: LOCKED implementation baseline for Golden Reference lessons U1.1 and U1.2.

## Principle
One lesson/activity package is authored once. E-LEAP adapts presentation automatically to viewport size; learners and teachers never choose a device type.

## Viewport behaviour
- Projector / large desktop: slide-like composition, 2-column layouts where pedagogically useful.
- Laptop / tablet: reduced chrome and flexible grids.
- Phone: single-column flow, touch-first controls, no required zoom.

## Interaction rules
- Minimum primary touch target: 44px.
- No essential action may depend on hover.
- Images/audio/video are fluid and may not overflow the viewport.
- Long/wide tables may horizontally scroll on very small screens rather than force page zoom.
- Submit/navigation controls remain easy to reach.
- Same canonical Resource ID and learning-event stream is used on all devices.

## Golden References
- U1.1: responsive retrofit applied without changing approved lesson content or answers.
- U1.2 FINAL v20: responsive retrofit applied without changing approved lesson content, answers or interaction logic.

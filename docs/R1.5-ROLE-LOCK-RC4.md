# R1.5 RC4 — HARD LESSON ROLE LOCK

RC3 defect: hosted lesson role enforcement lived outside the lesson controller, so U1.1 could still expose its own role switch in some runtime paths.

RC4 fixes role enforcement inside both Golden lesson controllers. Hosted Student/Guest is normalized to Student; hosted Teacher/Admin may use Teacher and Presentation only. Direct standalone QA behavior remains unchanged.

This is Preview runtime enforcement. Production security against localStorage/DevTools still requires authenticated, server-issued role/session authorization.

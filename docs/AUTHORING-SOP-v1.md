# E-LEAP Authoring SOP v1.0

## Standard workflow
Source material -> structured lesson data -> activity mapping -> E-LEAP Design System -> media references -> role/policy injection -> Preview (Student/Teacher/Presentation) -> Quality Check -> Publish.

## Author responsibilities
Teacher/Editor validates subject content, answer keys, media rights, and AI suggestions. The platform owns layout, typography, responsive behavior, interaction mechanics, and event logging.

## Default rule
From U2 onward, target at least 90% template + data + resource. Lesson-specific JavaScript/CSS requires an explicit exception and architecture review.

## AI authoring boundary
AI may parse, classify, split, suggest layout/activity, draft distractors, and prepare metadata. It may not publish subject content or overwrite source-locked medical/pharmaceutical terminology without human review.

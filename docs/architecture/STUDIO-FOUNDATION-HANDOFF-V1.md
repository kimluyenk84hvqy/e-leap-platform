# Foundation → Studio review-only handoff (Preview)
A teacher or admin in Foundation Lab can explicitly send a parsed **single Reading task** into the current Studio draft. Handoff uses **same-tab sessionStorage with a ten-minute expiry**, not a network upload or permanent local file.
- Studio requires its existing authenticated Teacher/Admin Studio-grant check.
- Studio prompts again before inserting a sourceReviewDraft screen after the current slide.
- Adapter creates the existing combo-screen format and ungraded response blocks, not a new activity renderer.
- Original textbook answer keys are not converted into interactive scoring keys. The common lesson Quality Gate rejects publication while sourceReviewDraft exists.
- Session storage is not a secure evidence authority; no browser flags can establish teacher-approved answers. Do not claim source verification.
- No deletion/reordering of existing screens. Cancel import leaves current lesson unchanged.
- Must still test UI handoff and source/role behavior on a real browser to sign off M3.

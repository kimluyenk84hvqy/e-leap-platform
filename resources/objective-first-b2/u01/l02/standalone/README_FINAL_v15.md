## Presentation cumulative answer reveal
- In Presentation mode, press **Check** to activate reveal mode.
- Click an individual answer box/question to reveal only that answer in place.
- Revealed answers remain visible while other answers are revealed and when moving between exercise tabs/screens.
- MCQ/T-F reveals the correct option in place.
- Reset clears the revealed answers for the current screen.
- Student/Self-study checking remains unchanged: learner answer -> Check -> correct/incorrect feedback + sound.

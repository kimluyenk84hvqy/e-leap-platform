# E-LEAP R4 RC1 — Class / QR / Live Session Transport

Baseline: R3C LOCKED FULL. R3C Golden References and Next/Previous are unchanged.

## RC1 scope
- Uses the existing `/api/research` database layer as the single live-session transport.
- Teacher Live Session page can create/reuse a cloud class, choose U1.1/U1.2, create a session, show a join code and locally generated QR, poll joined students and submitted responses, open the lesson in the same session, and end the session.
- Student `join.html` requires join code + existing school Student ID + full name, remembers the student profile locally, joins the cloud session, and opens the correct lesson with session/class/participant context.
- Lesson host forwards student learning events to `/api/research/events` when a live session is active.
- Teacher/Admin lesson host polls submitted live responses for the active session so the existing R3C Responses Hub can display cross-device responses.
- Guest Practice remains outside learner/session persistence.
- Platform Classes screen now exposes `Start Live Session`; Student Classes exposes `Join Live Class`.
- QR SVG is generated by the platform (`/api/qr`) using the `qrcode` package; no third-party QR service is required.

## Intentionally not locked yet
RC1 is a Preview transport checkpoint, not the R4 lock. Server-side authenticated teacher ownership/RBAC and production load/concurrency verification remain for the next R4 pass. Existing Research API routes predate R4 and currently depend on the configured Research DB environment variables.

## Regression protection
- U1.1/U1.2 remain Golden References.
- Next/Previous implementation is untouched.
- R3C unified top controls remain the owner of Submit / Presentation / Timer / Responses.
